# 文件篮与拍照交互

本轮用“文件篮＋拍照”替代162141的独立检查照片流程。我的文件仍是单独产品tab，不作为拍照中转页。用户主要在Android平板使用；桌面Chromium尺寸/触控模拟与实体设备验收分别记录。

## 全屏相机

取景铺满实际visual viewport，控件绝对定位覆盖画面，不用顶栏/底栏压缩video。竖屏快门在底部中央，横屏在右侧中央；通常72px，极矮横屏64px。返回、切镜头和连续拍摄按钮至少44px，预留左右/上下安全区。模式只有普通照片与文档扫描，配置在相机内，扫描包含几何矫正和保色增强。

连续默认开启，一次快门采样结束后留在相机；关闭连续则采样结束返回篮子。采样最长1秒、最多20个不同源帧，Endpoint质量够用提前停止；上传/PNG编码/扫描仍可后台继续，不把它们计作采样。相机界面不显示分数或强制完成按钮，篮子入口显示最新缩略图与数量。队列满时保留退出入口，只暂禁快门。

预览使用中心cover，普通输出来自完全相同的源矩形；不镜像文档文字，也不把屏外内容偷加进结果。快门时冻结取景尺寸与模式，旋转中取消尚未完成采样。原快照直接来自本机摄像头，不经串流视频编码；临时分析JPEG不作为保存照片，最终原图PNG与Endpoint扫描PNG对应同一快照。

## 紧凑文件篮

默认图片视图为横向strip，右侧竖排44px发送、添加、更多图标，内边距6px。紧凑卡片96×124，预览92高，名称/状态两行；缩略图contain完整显示。原生input有可靠位置时锚定其附近，否则同一布局居中Dialog。标题、长来源域名、操作说明和底部按钮栏不常驻。

卡片整卡拖拽，无手柄；点击打开该项的内联操作区域。触屏短滑浏览、长按200ms排序。单选Radio保持独立44px触控区域；点击卡片不会暗中选择。普通文件至少3个且占比至少2/3时默认列表，使用手柄、直接动作按钮；更多中可手动切换，本界面实例内保持，不持久化。待处理占位存在时暂停排序；已有就绪项仍可查看。

候选、大图、来源选择、更多与分组在同一篮子内替换式展开。默认strip实测148px高；候选/大图展开最多560px，普通来源/更多最多360px，均受视口减16px与实际锚定空间约束，内部滚动。锚定至少需要156px可用高度。更多包含来源/数量限制、视图切换与关闭选择。插入沿用所选ID，添加来源为设备、相机、我的文件，不增加检查照片界面。文件篮以外的档案图卡保持较大尺寸及时间排序。

## 拍后状态与确认

快门创建稳定临时任务和占位。任务由FileLibrary provider持有，退出相机不会丢掉已采样照片；最多两个任务，原快照与编码图均有预算。按快门顺序导入；前项失败时后项等待重试或移除。移除上传/处理中的任务会取消并丢弃迟到结果。Control提交在途期间暂禁该项移除，避免把已生效操作误说成取消；失败按原operation ID及冻结参数重试。

清楚、无歧义照片自动就绪。仅真实不确定时显示待选片，点候选先比较，再明确使用；确认后继续该项冻结的扫描模式。扫描失败要求在篮内重试或明确使用原图，不静默当扫描完成。低清晰度警示持久保存，但不强制多走确认。重拍保留旧条目，直到新图就绪或候选确认后原位替换；取消/失败保留旧图。

单文件input必须手动选定就绪项；multiple按当前顺序发送全部，有任何处理中/待确认项就禁用全部发送。只有Browser原生终态确认后才出篮并归档，未知结果保持文件和原事务。分组存在时发送/上传明确选择分组或不分组。
