# Endpoint 拍照评分与彩色扫描验证

2026-11-04，使用现有 Endpoint Release 构建的生产照片处理静态库。CTest `endpoint_photo_processing` 通过。另用独立进程直接调用同一份库，每个输入连续处理五次，记录完整 WIC 解码、几何判断、校光和 PNG 写入的墙钟时间及进程峰值工作集。源文件处理前后的 SHA-256 一致。探针、PNG 和输入/输出对照图在 `develop/tmp/photo-pipeline-native-20261104/`。样本来源及合成方式见[前期调查](document-scan-research-20261104.md)。

## 增量选片

固定 512×394 JPEG（WIC 质量 0.70）得分为清晰文字 0.763、横向模糊 0.488、同一文字减曝光 0.211、随机噪声 0.000。评分是有界清晰度启发式。早停要求两帧均达到 0.60、内容近重复、且当前没有实质不同的接近质量候选。清晰帧可替换模糊帧，单独一帧不触发早停，轻微曝光变化的第二清晰帧触发早停并保留一张原始快照。不同色彩但相近质量的两帧保留两张；结束阶段移除的赢家不可被选择。CTest 还检查了重复或不可用的 ID、513 像素分析边长、44 KiB 上限和取消。

## 几何与输出

合成完整梯形纸页通过自动透视，显式四点也通过，输出为无损 PNG。缺少页边的文字样本分别以 ±7.5° 拍摄角度通过 deskew，扩张画布在预期位置保留两侧边缘标记。对齐的截断页和内部深线表格均保留全视野。超过像素预算的图像明确拒绝。3840×2160 的 8,294,400 像素源图成功输出相同尺寸。
