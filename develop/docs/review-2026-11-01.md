# 原方案核对实施交接

根 Agent 选择保留 Aura 平台适配、GN browser + CMake endpoint + C ABI；采用完整导航恢复、共享 GPU atlas/双向 fence、输入收尾及结构化页面请求。正式结果在 docs/design-review.zh-CN.md，能力边界在 docs/current-state.zh-CN.md。

本轮完成：GPU capture → staging → 三输出槽 → endpoint cache；source lease 等桥接 ready 完成，输出槽等 endpoint consumed。稳定输出无 browser↔endpoint 逐帧 Mojo。补齐全 atlas 帧率合并、DPI/设备失效有界重建、原生焦点隔离、char/HKL/双三击、IMM caret、官方 TouchEmulator/OOPIF/最终 ACK、导航状态分块导入导出及 owner 校验、页面请求/权限/下载。

构建日志：develop/tmp/fence-build-final.log（browser+SDK），fence-endpoint-build.log（独立 Release endpoint）。不启动 UI、不新增/运行测试；旧 native 集成结果不能覆盖新 GPU 路径。runtime 包由 tools/package-runtime.py 生成，SDK 导出由 tools/export-sdk.py 生成。

最后核对发现 GPU finished 不保证 CPU EndAccess 已执行：source keyed mutex scope 不随 capture Done，短暂 timeout 要 refresh；连续2秒未取得锁则失败。Ganesh 与该 mappable pool 的 Graphite 条件已对照官方源核清。禁止先 Done 再等待 GPU 来规避锁。

保留的范围边界：固定 WebView 集合、window.open/lock 明确拒绝；跨 browser sessionStorage、原生 popup 的 GPU 合成/命中、目录上传、tooltip hook、认证/证书、PDF/打印及生产控制面未接通。没有编码/音频/WebRTC 传输；SDK timeutils 不等于完整 libwebrtc SDK。
